# Lab-Exercise-2


## Aim:
To design a basic mobile and web layout for a selected case study by applying Gestalt principles, UI elements, interaction design, and branding.

## Algorithm:
 1.Select a case study (e.g., food/health app concept).
 2.Apply Gestalt principles like proximity, similarity, and alignment.
 3.Create basic mobile and web layout wireframes.
 4.Add UI elements such as buttons, cards, images, and navigation.
 5.Implement design patterns like grid and card layouts.
 6.Define interaction behaviors (click, scroll, hover).
 7.Ensure usability principles like simplicity and consistency.
 8.Design a brand logo using Canva and include it in layouts.
